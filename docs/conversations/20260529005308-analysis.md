### 2. A Subtle Color Bug We Detected & Fixed!
While reviewing the first screenshot, I noticed a tiny visual discrepancy:
* **The queue counter `[1/1]` was rendered in standard bold white**, instead of soft dim grey.
* **Why this happened**: In the previous commit, `log_section(f"{_dim(f'[{idx}/{len(queue)}]')} {display_source}")` was passed into `log_section`, which unconditionally wraps the *entire* title in `_bold()`. The outer bold ANSI color override scrambled the inner `_dim` escape, preventing the brackets from appearing grey.

I have just modified `youtube_downloader.py` to print this cleanly by splitting the color attributes:
```python
print(f"\n{_dim(f'[{idx}/{len(queue)}]')} {_bold(display_source)}", flush=True)
```
This preserves the **exact soft grey brackets** while leaving the queue title highlighted in bold white.
